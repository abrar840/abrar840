## About

I build web applications end to end: **TypeScript and React** on the front, **Python (FastAPI) and Laravel** on the back, **PostgreSQL and Redis** underneath. Over the past year I have shipped features for multi-tenant SaaS products, traced a silent data-loss bug in a Python pipeline to its root cause, and cut a page's requests from 107 to 6.

I use **Claude Code** and **Cursor** daily, and every generated change is reviewed and tested before it ships.

> **Currently building:** a Retrieval-Augmented Generation (RAG) legal assistant from scratch. Section-aware chunking of a national legal code, Gemini embeddings in Supabase pgvector, cited answers from a FastAPI service, a React client. API on Render, client on Vercel. Repository goes public with v1.
